==================================================
НАЗВАНИЕ ПРОЕКТА: Игра "Ним" (Nim Game)
==================================================

КРАТКОЕ ОПИСАНИЕ
--------------------------------------------------
Классическая математическая игра "Ним" для двух игроков.
Реализована на Python с использованием графического фреймворка PyQt5.
Игроки по очереди берут камни из общей кучи. Проигрывает тот, кто забирает последний камень.

ПРАВИЛА ИГРЫ
--------------------------------------------------
- Начальное количество камней: 15.
- За один ход можно взять 1, 2 или 3 камня.
- Игроки ходят по очереди.
- Игрок, который забирает ПОСЛЕДНИЙ камень, проигрывает.
- В игре предусмотрены экраны:
    * Главное меню (старт игры)
    * Игровой экран (кнопки выбора 1-3 камней, кнопка "Взять")
    * Экран поражения
    * Экран победы
